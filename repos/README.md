## History kaise preserved hai

Har import ek **merge commit** hai jiske 2 parents hain:

1. Pehla parent = OmniRoute ka us waqt ka HEAD
2. Dusra parent = source repo ka original commit

Isliye source repo ki poori history (saare commits, authors, dates) object store mein
maujood hai. Kisi bhi sub-repo ki original history dekhne ke liye:

```bash
# merge commit ke dusre parent ko follow karo
git log --follow repos/n8n/

# ya seedha source commit se
git log 5f9602b19e4b513c939af44cea5ea7ede58b0555
```

## Kisi sub-repo ko update karna

```bash
git subtree pull --prefix=repos/n8n \
  https://github.com/duniyakarahasyamedia-hash/n8n.git master
```

## Kisi sub-repo ko wapas alag nikalna

```bash
git subtree split --prefix=repos/n8n -b n8n-extract
```
